01 归一化 (Normalization)1.为什么要做归一化归一化的核心思想：控制数据分布的尺度 归一化的好处： 梯度稳定：反向传播时梯度不会消失或爆炸 学习率容忍度高：可以用更大的学习率，加速训练 深层网络可训练：可以堆叠更多层而不崩溃 2.怎样做归一化按统计维度划分：BN / LN 等 BatchNorm (BN)： 沿 N, H, W 统计，对每个通道 C 单独计算。训练时依赖当前 batch 的统计量，推理时使用训练期间累积的 running mean/var。缺点是对小 batch 敏感，且训练/推理行为不一致。主要用于 CNN 图像分类等任务。 LayerNorm (LN)： 沿 C, H, W 统计，对每个样本 N 独立计算，与 batch 大小完全解耦。训练和推理行为一致，适合变长序列（RNN/Transformer），但计算开销比 RMSNorm 大（需要同时算均值和方差）。 按Transformer 中的放置位置划分：Pre-Norm / Post-Norm / 混合方案 类型 归一化位置 公式 优点 缺点 ...
